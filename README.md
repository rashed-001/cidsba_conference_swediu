# IEEE CIDSBA 2024 Conference Website

Official website for the IEEE International Conference on Computational Intelligence, Data Science and Business Applications (CIDSBA) organized by the Department of Software Engineering, Daffodil International University.

## 🌟 Features

### Core Features
- ✅ Responsive design optimized for all devices
- ✅ Modern, professional UI with Tailwind CSS
- ✅ Complete conference information
- ✅ Committee member listings
- ✅ Paper submission guidelines
- ✅ Registration information
- ✅ Contact form

### Additional Features
- ⏱️ **Countdown Timer** - Live countdown to submission deadline
- 📰 **News & Updates** - Latest conference announcements
- 👥 **Speaker Profiles** - Detailed keynote and invited speaker information
- 📅 **Interactive Schedule** - Complete conference program with timeline
- 🖼️ **Photo Gallery** - Conference highlights and past events
- 🤝 **Sponsors Section** - Recognition of conference sponsors
- ❓ **FAQ Section** - Comprehensive frequently asked questions
- 📥 **Downloads Center** - Templates, guidelines, and materials
- 📧 **Newsletter Subscription** - Stay updated with email notifications

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Icons:** React Icons
- **Deployment:** Vercel
- **Language:** JavaScript/React
